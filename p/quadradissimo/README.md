# Quadradissimo

Quadradissimo é um pequeno projeto pessoal sobre websocket em PHP e canvas em javascript. É um mini jogo online onde os personagem são quadrados, e voce pode interagir com outros jogadores
# Recursos Principais:

Multijogador em Tempo Real: Utilize WebSockets para permitir que vários jogadores se conectem e interajam simultaneamente, criando um ambiente de jogo vibrante.
Gráficos em Canvas: A interface do jogo é construída com HTML5 Canvas, proporcionando gráficos suaves e animações envolventes.
Interação entre Jogadores: Os jogadores podem movimentar seus quadrados, interagir com outros jogadores e participar de competições amigáveis.

# Tecnologias Utilizadas:

- Frontend: HTML5, CSS3, JavaScript (Canvas)
- Backend: PHP (WebSocket)
- Banco de Dados: MySQL (para armazenar informações dos jogadores e estatísticas)// ainda nao implementado
